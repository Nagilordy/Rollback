# Download

Rollback is free. Get the latest version from the [Releases page on GitHub](https://github.com/Nagilordy/Rollback/releases). Version 0.1 is a pre-release for **Linux**; Windows and SteamOS come next.

| System | File | How to install |
|---|---|---|
| **Linux** | `Rollback-x86_64.AppImage` | Make it executable (right-click → Properties → allow running as a program), then open it. |
| **Windows 10 / 11** | `RollbackSetup.exe` (coming soon) | Run it. Updates install over the old version, and your settings stay. |

Nothing else to install.

::: tip Test builds
Versions marked **Pre-release** on GitHub are test builds: newest features, possibly rough edges. If you try one, [tell us what breaks](https://github.com/Nagilordy/Rollback/issues/new?template=bug_report.yml).
:::

## What you need

- A **Jellyfin** server (10.9 or newer recommended), on your network or reachable over the internet.
- That's it. Sign in with your usual Jellyfin profile.

No server yet? [Set up from scratch](/guide/setup) shows how, step by step.
